# Проверка демонстрации · 24.10.2026

## Автоматические проверки

`npm test`: 43 проверки Vitest (доменная модель и HTTP API), включая ветвление, исключающие варианты времени, обработку неизвестной цены, контакт, снимки всех показанных программ, двойную отправку, сбой записи/чтения, повтор, версии, закрытие и историю. API проверяется настоящими HTTP-запросами Supertest с синтетически подписанной initData: нет подписи / подмена / срок / чужой владелец / права администратора / неверный Origin / валидация / авторитетная цена / идемпотентность. Проверено сохранение SQLite после закрытия и повторного открытия файла. Реальных токенов и контактов нет.

`npm run build`: TypeScript и production-сборка Vite. `npm audit`: известных уязвимостей на момент проверки не найдено.

## Проверено через интерфейс Chromium (Playwright CLI)

1. B → с нуля → автомат → будни, вечер → ближайшее время. Вопрос «Оплата частями», выбор «Стандарт» АКПП.
2. Из проверки заявки выполнено редактирование графика: добавлены выходные. Опыт, автомат, программа и вопрос сохранились. После обновления страницы черновик на том же шаге.
3. Пустое имя, пустой и неправильный Telegram-контакт вызывают ошибку. Кнопка тестовых данных заполняет явно тестовое обращение.
4. Через временную подмену браузерного Storage API вызвана ошибка записи заявок. Экран успеха не появился, контакт и ответы остались. После восстановления записи и двойного нажатия «Повторить» создана ровно одна заявка.
5. В роли администратора открыт тот же номер с исходными ответами и контактом. Сотрудник сохранил вопрос о выходных; ученик увидел его и ответил; ответ появился у администратора.
6. Сотрудник предложил реальный «Стандарт» АКПП с комментарием. Ученик отметил интерес. После обновления: предложение, интерес и четыре сообщения на месте, исходные ответы сохранены.
7. Новый черновик не заменяет ранее созданную заявку. B с автоматом изменена на A: опыт и коробка очищены, вопрос про автомобильную коробку отсутствует.
8. A с нуля → гибкий график, неизвестное время, пока выбираю → пропуск вопросов → продвинутый мотокурс. Базовый сезонный курс новичку не предлагается.
9. Смена направления на «Пока не знаю» → общая консультация. Общие пожелания по графику сохранились. Можно создать отдельную заявку без тарифа; предыдущая осталась в списке.
10. FAQ раскрывается, содержит официальные ссылки; внешние чаты сами не открываются. Визуально просмотрены desktop 1440×1000 и узкие окна 390×844, 360×800. Горизонтальной прокрутки на проверенных экранах нет. Переключатель ролей остаётся доступен при прокрутке.

В ходе проверки исправлены возврат в новый черновик после отправки, сохранение текущего шага при переходе в служебные разделы, доступные названия кнопок и повтор после недоступности хранилища.

## Границы проверки

**Физический телефон:** не использовался. Ширина мобильного окна — эмуляция viewport в Chromium, не проверка реального iOS/Android WebView. Нативная экранная клавиатура и реальные safe area телефона не проверены; поля имеют размер шрифта 16 px, нижняя панель не фиксирована поверх полей, учтены CSS safe-area отступы и reduced motion.

**Telegram:** подготовлен код, но реальный отдельный бот не запускался. Синтетические тесты алгоритма подписи и API не равны интеграционной проверке Telegram. Токен, тестовый администратор, реальная доставка уведомления, HTTPS API и работа с другого физического устройства требуют настройки по README. Существующий бот школы и учебная платформа не затрагивались.

**Публикация:** GitHub Pages разворачивает только frontend. Workflow успешно выполнил тесты, сборку и публикацию. Публичный https://artemdiscipline.github.io/avtofakultet-demo/ открыт в Chromium без авторизации. HTML, JS, CSS, favicon, фотография и шрифты вернулись с HTTP 200. Проверены пустой список администратора, прямое открытие hash-маршрута FAQ и обновление страницы. Сервер и бот на Pages не работают.

Дополнительно проверено переключение из администратора в ученика после полной перезагрузки карточки: открывается та же заявка.
